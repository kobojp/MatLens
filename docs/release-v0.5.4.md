# MatLens 0.5.4：案件資料夾名稱加入材料

- 新案件資料夾在定址碼與問題之間加入選取的材料，包含自訂材料。
  例如：`二門診3F M2-5 排煙風門馬達 故障`。
- 月份模式與自由路徑模式的畫面預覽、實際儲存名稱同步；自由路徑仍可選擇是否加入日期。
- 掃描與磁碟照片總覽可從新格式辨識材料，並相容未包含材料的舊資料夾格式。
- 保留自訂材料及問題名稱中的空白；刪除快速選項後，既有案件仍可辨識。

既有案件與照片資料夾保持原名，新命名規則適用於新儲存的案件。

## 安裝與更新

- 新安裝：下載 `MatLens-0.5.4-win-x64.zip`，完整解壓縮後執行 `Install-MatLens.cmd`。
- 已安裝支援線上更新的版本：先儲存案件，再由程式內檢查更新、下載並手動安裝。
- `MatLens-0.5.4-update-win-x64.zip` 為線上更新專用包。

資料相容版本維持 1；案件資料庫及照片與程式檔案分開儲存。
