# MatLens 0.5.6 — 藍白照片工作區、圖片貼上與更新紀錄

- 新增案件統一使用根目錄及子資料夾，移除月份模式切換；既有案件與月份資料夾可照常讀取。
- 保存根路徑、子資料夾與日期前綴設定，重新開啟後還原；目錄失效時明確提示重新選擇。
- 上方以醒目色標示目前儲存資料夾（新版淺藍、原版青綠），顯示完整目的地，捲動畫面時仍可查看。
- 新增「貼上圖片」與照片區 Ctrl+V；確認預覽後才加入照片，取消不影響案件。
- 桌面版可讀取 Windows 圖片及圖片檔案剪貼簿；單張最多 25 MiB，一次貼上總大小最多 75 MiB。
- 更新器保留各階段紀錄與自測失敗原因，可在「關於與更新」查看本機診斷。
- 新增更新 log 與「開啟更新紀錄」：依工作編號保存檢查、下載、驗證、更新器、回復與重啟結果，失敗保留例外與錯誤堆疊，重開後仍可查看。

- 新版預設藍白照片工作區：匯入／貼上集中在照片區，大圖塊顯示角色及命名，可拖曳排序。
- 點照片開啟放大視窗，可縮放、拖曳、左右換圖及 Esc 關閉，關閉後回到原照片。
- 新增「設定 → 介面配置」，可切回原版三欄，或選照片圖塊搭配右側／上方案件資料。
- 支援上方資料收合與摘要、中／大圖塊、恢復預設版面；SQLite 保存偏好，重開沿用。
- 切換配置及恢復版面保留目前照片、角色、案件欄位與儲存位置。

其他電腦更新後仍停在舊版的問題尚待該機證據與實機回歸，不能將本機隔離驗證視為已修復。

安裝請下載 `MatLens-Setup-0.5.6-x64.exe`，執行後按「下一步」，可建立桌面捷徑。
程式位於 `%LOCALAPPDATA%/MatLens/app`，資料庫位於同一根目錄的 `matlens.db`；升級保留案件與照片。
既有桌面版可在「關於與更新」檢查更新、下載後按安裝並重新啟動，再核對目前版本為 0.5.6。

本版通過 162 個後端測試、56 個前端測試、桌面 EXE 自測、隔離安裝／重裝與舊版升級驗證。
完整更新紀錄需先安裝本版；無法回補 0.5.4／0.5.5 過去的失敗。
