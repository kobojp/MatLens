# MatLens 0.4.0：月份與子目錄指定儲存

- 依維修日期預選 `1月` 到 `12月` 的月份資料夾。
- 掃描月份下的既有子目錄，讓使用者選擇 `底座`、`模組`、`探頭` 或其他目錄。
- 月份不存在時顯示提示，可一次建立月份與多個常用／自訂子目錄。
- 新案件只在選定的子目錄建立案件資料夾，不再自動加入年份與材料層級。
- 儲存前再次驗證目的目錄，拒絕路徑跳脫及不安全的 Windows 目錄名稱。
- 保留既有案件記錄的儲存根目錄與相對路徑，不搬移、重新命名或刪除既有照片。

## 安裝與更新

第一次安裝或手動升級，下載 `MatLens-0.4.0-win-x64.zip`，完整解壓縮後執行
`Install-MatLens.cmd`。已安裝 v0.3.0 或 v0.3.1 可在「關於與更新」下載並安裝。

案件資料庫、現場照片、簽章私鑰與開發虛擬環境不包含在原始碼或下載包中。

## 已知限制

- Windows 11 x64 已實測；Windows 10 仍待實機驗證。
- EXE 尚未使用 Windows Authenticode 簽章，SmartScreen 仍可能提出警告。
- 需要 Microsoft Edge WebView2 Runtime。
