# MatLens 0.3.0：線上更新

> 歷史版本說明：自 0.3.1 起，原始碼與下載已統一至公開 `kobojp/MatLens`。

- 新增「關於與更新」：啟動檢查正式版、手動選擇測試版、下載進度及確認安裝。
- HTTPS 下載；Ed25519 簽章驗證更新資訊，SHA-256 驗證更新包。
- 未儲存或正在儲存的案件會阻止更新，不強制結束原程式。
- 更新前備份 SQLite，使用獨立資料試跑新版，再替換程式。
- 安裝或啟動失敗會嘗試回復舊程式，保留舊程式目錄與備份。

## 第一次安裝

下載 `MatLens-0.3.0-win-x64.zip`，完整解壓縮後執行 `Install-MatLens.cmd`。
舊版沒有更新功能，因此這一次需要手動安裝；往後可在程式內更新。
請勿下載 `update-win-x64.zip` 作為第一次安裝包。

## 注意

- 原始碼倉庫維持私人，此處僅發佈程式與更新資訊；不含案件或照片。
- 更新包簽章不等於 Windows Authenticode 簽章，EXE 尚未簽署，可能出現 SmartScreen 提示。
- 需要 Windows x64 與 Edge WebView2 Runtime；已在 Windows 11 實測，Windows 10 仍待實機驗證。
- 自動更新僅適用 `Install-MatLens.cmd` 的預設安裝位置；開發版／直接解壓版可檢查更新，但需手動安裝。
- 不包含先前討論的月份資料夾掃描功能，那是另一項待開發需求。
