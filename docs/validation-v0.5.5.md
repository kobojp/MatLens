# MatLens 0.5.5 本機驗證

驗證日期：2026-10-19。此記錄涵蓋 0.5.5 本機交付候選；原始碼推送與 GitHub Release
分開處理，公開正式版仍為 0.5.4。

## 本次行為

- 清冊顯示目前後端使用的資料庫，可在檔案總管選取該資料庫。
- 更新畫面顯示版本、執行檔、資料庫與執行方式。
- 更新交接記錄工作與目標版本，舊成功紀錄不能掩蓋尚未完成的新更新。
- 更新後仍開啟較舊版本時，明確顯示尚未在此程式生效。
- 繁體中文安裝精靈預設安裝到 `%LOCALAPPDATA%/MatLens`，不要求管理員權限。

```text
MatLens/
├─ app/                 程式與執行依賴；更新僅替換此處
├─ matlens.db           沿用既有桌面資料庫
├─ backups/
├─ logs/
├─ updates/
├─ photos/              預設照片位置；既有自訂位置仍沿用
└─ uninstall/           安裝精靈的解除安裝程式
```

## 驗證範圍與待追蹤事項

本次沒有安裝到使用者的正式目錄，也沒有變動既有案件或照片。安裝驗證使用獨立 QA 身分與
暫存捷徑目錄；採無介面安裝測試，沒有逐頁人工檢查精靈版面。

首次原始碼自測發生一次 `WebView2 flow timed out`，當時尚未存入案件。
加入逾時步驟診斷後，後續原始碼、EXE 與隔離更新均通過，未再次重現；原始失敗報告
`source-self-test-v0.5.5.json` 保留。這次不能據此宣稱已找到逾時根因，正式發佈前仍須評估。

目前留下的使用者機器更新紀錄不足以確認原先「重開仍未更新」的確切根因。
已修正可重現的錯誤成功提示、支援新舊安裝路徑並增加執行資訊；若再次發生，
應使用當次執行版本／位置與同一工作識別碼的更新紀錄診斷，不能將舊成功報告視為本次完成。
