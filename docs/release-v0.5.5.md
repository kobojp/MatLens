# MatLens 0.5.5

- 案件清冊可顯示目前使用的資料庫路徑，按「開啟資料庫位置」在檔案總管選取該資料庫；按鈕採一致的圓角與藍灰色樣式。
- 「關於與更新」顯示實際程式、資料庫位置及執行方式；重開後仍執行舊版本會明確提示尚未生效。
- 新增繁體中文安裝精靈，免管理員權限，依序按下一步，可選擇桌面捷徑，並建立開始功能表捷徑。
- 統一管理於 `%LOCALAPPDATA%\MatLens`：程式在 `app\`，既有 `matlens.db` 路徑保持不變。
- 舊安裝位置仍支援簽章線上更新。更新只替換程式，安裝與解除安裝都保留案件、照片、備份及紀錄。

首次安裝或整理舊捷徑時，執行 `MatLens-Setup-0.5.5-x64.exe`，先儲存並關閉 MatLens，
再依精靈完成安裝。既有自訂照片位置不變；桌面與網頁資料庫仍各自獨立。

若線上更新顯示預先測試失敗，原版本與資料會保留，可稍後重試或改用完整安裝精靈。
