# MatLens 0.5.7

- 火警細項可獨立新增／刪除自訂選項，只有選擇火警才展開，與一般問題各自管理。
- 接續既有自訂問題作為初始細項，不移除原問題或更動已儲存案件。
- 新增「火警資料夾名稱包含材料」並保存偏好；省略名稱中的材料仍保留案件材料與儲存子目錄。
- 新建火警名稱改用空白分隔，例如「二門診1F M3-01 火警 底座故障」，定址碼內的連字號維持不變。
- 掃描相容舊連字號與新空白格式，不自動重新命名既有資料夾。
- 案件清單按「編輯」直接載入原主工作區，可更正資料、新增／貼上／移除照片、排序、改角色及縮放，儲存同一筆案件。
- 保留背景新增草稿，結束編輯還原；儲存後留在同案。既有照片不重傳、不重新編碼，照片異動保留完整原檔備份。
- 更名前確認原／新完整路徑；沿用該案原儲存位置，同名衝突不覆蓋，編輯前建立 SQLite 備份。
- 儲存更正改用主題配色的置中確認視窗，原／新資料夾分區呈現；長路徑完整換行，小視窗內可捲動且底部按鈕保持可見，取消或 Esc 保留草稿。
- 編輯加入外部變動檢查、失敗回復及中斷更名恢復；未知來源的資料夾更名需確認為整理結果。

編輯沿用該案原根目錄及父目錄。另一台電腦的更新問題 UPD-001 仍待該機驗收。

## 安裝與更新

下載 `MatLens-Setup-0.5.7-x64.exe`，執行後依精靈按「下一步」，自動指定安裝位置並可建立桌面捷徑。
既有桌面版可在「關於與更新」檢查、下載並安裝更新；請先儲存目前工作。
更新只替換程式，保留案件資料庫與照片，並在更新前建立 SQLite 備份。
